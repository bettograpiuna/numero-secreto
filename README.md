# Jogo do Número Secreto

Bem-vindo ao Jogo do Número Secreto\! Este é um projeto divertido e interativo desenvolvido como parte dos estudos de lógica de programação em JavaScript, em colaboração com a Alura. O objetivo do jogo é adivinhar um número secreto gerado aleatoriamente.

## 🎮 Como Jogar

1.  O jogo irá gerar um número secreto entre 1 e 10.
2.  Você deve inserir um palpite no campo de entrada e clicar em "Chutar".
3.  O jogo informará se você acertou ou errou, e se o número secreto é maior ou menor que o seu palpite.
4.  Continue tentando até descobrir o número secreto\! O jogo também conta em quantas tentativas você conseguiu.

## ✨ Funcionalidades

  * **Geração de Número Aleatório:** Um novo número secreto é gerado a cada nova partida.
  * **Validação de Entrada:** O sistema guia o jogador com dicas (maior/menor).
  * **Contador de Tentativas:** O jogo informa ao usuário quantas tentativas foram necessárias para acertar.
  * **Design Responsivo:** A interface se adapta a diferentes tamanhos de tela.
  * **Interação por Voz (Web Speech API):** O projeto inclui uma funcionalidade de reconhecimento de voz, permitindo que o usuário fale o seu palpite em vez de digitar.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias:

  * **HTML5:** Para a estrutura semântica da página.
  * **CSS3:** Para a estilização e o design responsivo.
  * **JavaScript:** Para toda a lógica do jogo, manipulação do DOM e interatividade.
  * **Web Speech API:** Para implementar o recurso de reconhecimento de voz.

## 🛠️ Como Executar o Projeto

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/bettograpiuna/numero-secreto.git
    ```

2.  **Navegue até a pasta do projeto:**

    ```bash
    cd numero-secreto
    ```

3.  **Abra o arquivo `index.html` em seu navegador de preferência.**

      * Não é necessária nenhuma instalação. O projeto é executado diretamente no navegador.
